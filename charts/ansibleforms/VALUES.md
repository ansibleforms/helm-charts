# Values reference

Every value the `ansibleforms` chart accepts, with its default. Generated from the `# --`
comments in [values.yaml](values.yaml) by [helm-docs](https://github.com/norwoodj/helm-docs);
do not edit this file by hand, edit the comment and regenerate:

```bash
helm-docs --chart-search-root charts --template-files VALUES.md.gotmpl --output-file VALUES.md --ignore-non-descriptions
```

The longer explanations, and the reasons behind the defaults, are in the comments of
values.yaml itself and in the [README](README.md).
