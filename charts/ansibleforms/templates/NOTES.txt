  speak TLS to the backend. On ingress-nginx that is an Ingress annotation,

{{ else if dig "generate" false (.Values.secrets | default dict) }}
  The chart made these up on the first install and reads them back on every
  upgrade afterwards, so they do not change. They exist nowhere but in that
  Secret: back it up, or you will be resetting the admin password and losing
  every credential AnsibleForms has encrypted.

{{- $enc := toString (dig "server" "env" "ENCRYPTION_SECRET" "" (.Values.applications | default dict)) }}
{{- if and $enc (ne $enc "<ENTER_SECRET_HERE>") (ne (len $enc) 32) }}
About ENCRYPTION_SECRET
{{ if lt (len $enc) 32 }}
  Yours is {{ len $enc }} characters. AnsibleForms uses it directly as an
  aes-256 key, so it pads anything shorter to 32 with a constant that is in its
  own source code: {{ sub 32 (len $enc) }} of those 32 bytes are public knowledge.
{{- else }}
  Yours is {{ len $enc }} characters. AnsibleForms cuts it to 32 before using it
  as an aes-256 key, so the last {{ sub (len $enc) 32 }} never count for anything.
{{- end }}
  Worth fixing on a new install. Worth thinking twice about on an old one: it is
  the key stored credentials are encrypted with, and changing it does not fail,
  it just quietly turns them into rubbish. Take a backup and re-enter them.
{{ end }}

Running playbooks

  Playbooks run on the RTE in the server pod ({{ dig "rte" "image" "" (.Values.containers | default dict) }}).
{{- if eq (include "ansibleforms.rte.seedEnabled" .) "true" }}
  The chart registered it as the default runner, "{{ dig "rte" "runnerName" "rte" (.Values.containers | default dict) }}", under Connections > Runners.
{{- else if eq $rteRegister "0" }}
  RTE_REGISTER is 0, so it does not add itself as a runner. Add it under
  Connections > Runners: type RTE, uri {{ include "ansibleforms.rte.url" . }}, tick Default,
  and the token from:

    kubectl -n {{ .Release.Namespace }} get secret {{ include "ansibleforms.rte.tokenSecretName" . }} -o jsonpath='{.data.{{ include "ansibleforms.rte.tokenSecretKey" . }}}' | base64 -d
{{- else }}
  It adds itself under Connections > Runners as "{{ include "ansibleforms.rte.selfName" . }}" ({{ include "ansibleforms.rte.url" . }}),
  the default unless another RTE runner already is, and keeps that one row across restarts.
{{- if eq (include "ansibleforms.rte.userSeed" .) "true" }}
