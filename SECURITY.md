# Security Policy

This repository is the Helm chart for AnsibleForms, so security problems in the
application belong to the application. Please follow the
[AnsibleForms security policy](https://github.com/ansibleforms/ansibleforms/security/policy)
and report privately through its
**[Report a vulnerability](https://github.com/ansibleforms/ansibleforms/security/advisories/new)** page.

**Please do not open a public issue for a security problem.**

If the problem is in the chart itself, for example a default that exposes a service, a
missing security context or a credential rendered where it should not be, use
**[Report a vulnerability](https://github.com/ansibleforms/helm-charts/security/advisories/new)**
on this repository instead.

Fixes land in the next 7.x chart, released with the next AnsibleForms 7 release. The 6.x
charts are final and get no further releases.
